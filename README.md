## 🔨 what i'm building

**[Eaglercraft 1.16.5](https://github.com/TECHYAko/Eaglercraft-1.16.5)** — full Minecraft 1.16.5 client + server ported onto the EaglercraftX runtime, compiled to WebAssembly with TeaVM. Real singleplayer worlds, real multiplayer, skins, resource packs — the actual game, running client-side in your tab.
